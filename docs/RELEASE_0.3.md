# دفتر 0.3.0 — إصدار تجريبي

- إضافة العملات يدويًا واختيار عملات التعامل لكل حساب.
- عملة ملخص لكل حساب وعملة ملخص عام، مع أسعار تحويل يدوية مؤرخة وتفاصيل الحساب.
- ظهور تنبيه عند نقص أسعار التحويل، دون تغيير أرصدة العملات الأصلية.
- تصدير Excel حقيقي، والبحث بالمبلغ والتاريخ والبيان والمرجع.
- ترقية بيانات النسخة السابقة دون حذف الحركات أو إعادة كتابتها، ونسخ احتياطية تشمل إعدادات العملات.

حمّل **Daftar_0.3.0.apk** وثبّته كتحديث للنسخة السابقة. Android 8.0 فأحدث. الحزمة وشهادة التوقيع محفوظتان؛ لا تحذف التطبيق القديم لتثبيت التحديث. احفظ نسخة احتياطية مشفرة قبل الترقية. النسخ الاحتياطية الجديدة لا تقرأها الإصدارات القديمة.

**هذه المرحلة تعمل على الجهاز.** قواعد الإدخال المستقل ومطابقة الإجماليات وحسم المراجع واعتماد الجهتين وقفل الفترة موجودة ومختبرة في الشيفرة، لكن التعاون بين الهواتف وتسجيل دخول الموظفين لم يُفعّلا بعد ويحتاجان الخدمة المركزية.

تفاصيل الفحوص وحدودها في [سجل التحقق](VALIDATION.md).
