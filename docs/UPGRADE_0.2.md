# دفتر 0.2 — نطاق التحديث المعتمد

- تسجيل مبسط: لي عنده / له عندي / استلمت منه / دفعت له، مع إبقاء القيد ومدين ودائن في التفاصيل.
- حسابات: عميل، وكيل، مورد، شخص، أخرى؛ المفضلة أعلى القائمة؛ مرجع الحجز/المعاملة اختياري.
- استحقاقات: تاريخ اختياري للدين، قائمة اليوم والمتأخر والقادم، تخصيص دفعة جزئية لدين واحد. الحركات القديمة تحتفظ بأثرها دون تخمين أنها دين أو سداد.
- سداد بعملة أخرى: تخفيض المستحق بعملته الأصلية وتوثيق مبلغ الدفع وعملته والسعر، دون إنشاء دين جديد بعملة الدفع أو ادعاء إدارة صندوق.
- تكرار: تحذير قبل الحفظ مع تأكيد صريح؛ لا يمنع العمليات الصحيحة المتشابهة.
- مرفقات: نسخ الصور/PDF إلى مساحة التطبيق؛ أسماء آمنة ومعرفات محتوى؛ تشملها النسخ الاحتياطية.
- PDF عربي متعدد الصفحات: الحساب والفترة ورصيد البداية والحركات ورصيد النهاية لكل عملة؛ حفظ ومشاركة.
- حماية: قفل النظام بالبصمة/رمز الجهاز؛ نسخ AES-GCM بكلمة مرور واشتقاق PBKDF2؛ كلمة النسخ الآلي محمية بمفتاح Android Keystore.
- نسخ آلي اختياري يومي وبعد تغييرات الدفتر إلى مجلد يختاره المستخدم؛ ملفات منفصلة لا تستبدل آخر نسخة سليمة؛ آخر نجاح/فشل ظاهر. الكتابة إلى مزود مستندات ليست إثبات اكتمال مزامنته السحابية.
- تذكيرات محلية اختيارية دون إرسال رسائل للعملاء؛ توقيتها يتأثر بقيود Android.
- ترقية غير مدمرة لبيانات 0.1 ونسخها، اختبارات التسوية والعكس والمبالغ والاستعادة والتشفير.
- توزيع: صفحة Releases وزر فتحها، إعداد توقيع مستقر خاص بالمالك؛ لا مفاتيح في المستودع.

المؤجل: الصناديق والبنوك والإيرادات والمصروفات وقياس الأرباح نظام محاسبي منفصل، وليست ضمن هذه الترقية لدفتر الذمم.
