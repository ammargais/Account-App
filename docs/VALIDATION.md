# سجل التحقق — دفتر 0.3.0

التاريخ: 7 نوفمبر 2026.

## الفحوص المحلية

نجح 61 اختبارًا: 23 للنواة، و14 لحالات التحديث السابقة، و5 لقاعدة البيانات والتكامل، و8 للعملات والملخصات، و8 لقواعد التعاون، واختبار Excel، واختبارا واجهة Robolectric.

شملت الفحوص إنشاء دفتر بلا عملات مبدئية، والدقة العشرية المخصصة، وصلاحية عملات الحساب، والأسعار المباشرة والعكسية والمؤرخة، ومنع إظهار إجمالي كامل عند غياب سعر، وبقاء القيود الأصلية كما هي. فُحص حفظ العملات والأسعار بعد إعادة فتح قاعدة البيانات، والتراجع الذري عند كتابة إعداد غير صالح، وترقية SQLite القديمة دون إعادة كتابة القيود.

اختُبرت المطابقة الداخلية: إدخال 15,000,000 مقابل ثلاث دفعات من 5,000,000، وعدم مضاعفة الرصيد، وإعادة الإرسال دون تكرار، وعرض إدخال الموظف وحده، وقرار المراجع مع السبب، واعتماد جهتين مختلفتين، وإلغاء الموافقة عند تغير البيانات، وقفل الفترة مع بقاء الفترة التالية مفتوحة. هذه اختبارات محرك القواعد؛ لا تثبت حماية خدمة شبكة لم تُربط بعد.

اختُبر تدفق الواجهة: إضافة عملة يدويًا، واختيار عملة الملخص، وإنشاء حساب وتحديد عملاته وملخصه، وإعادة إنشاء Activity، ثم تسجيل دين وسداد جزئي. اختُبر أيضًا دين 100 USD وسداد 40 USD بدفع فعلي 147 AED، مع بقاء 60 USD دون إنشاء رصيد دين بالدرهم. روجعت صور الشاشات الفعلية المنتجة بواسطة Robolectric ببيانات اصطناعية.

اجتاز `testDebugUnitTest lintDebug assembleDebug`؛ لا أخطاء lint، مع 18 تحذيرًا وملاحظة تحسين تتعلق بأسلوب الشيفرة وإعداد استخراج البيانات. فُتح ملف XLSX الناتج بواسطة openpyxl: ورقتان بالعربية، واتجاه RTL، وحفظ الأرقام التي تتجاوز دقة Excel كنص دون فقد قيمتها، وعدم تفسير نصوص المستخدم كمعادلات.

## التوزيع وفحوص جهاز أندرويد

يُبنى ملف release بنفس اسم الحزمة وشهادة النسخ السابقة. يفحص `scripts/verify_distribution.py` نسخة APK مقابل بصمة المصادر والملف والشهادة ورقم الإصدار وعدم قابليته للتنقيح، كما يتحقق CI منها قبل النشر. البصمات في `distribution/release.json`.

مهمة `device` تختبر PDF الأصلي وAndroid Keystore على محاكي Android 15. النشر على GitHub مشروط باجتيازها واجتياز فحوص النواة والواجهة. ارجع إلى تشغيل GitHub Actions المرتبط بالتعديل لمعرفة نتيجة CI الفعلية.

## حدود التحقق

لم يُثبّت التحديث على هاتف Ammar أثناء هذه الجلسة. حوار البصمة، وإذن الملفات، ومزود Google Drive، والمشاركة مع تطبيق خارجي، والجدولة تحت قيود بطارية Samsung تحتاج تجربة على هاتف المستخدم.

هذه النسخة محلية. التعاون عبر الهواتف، وتسجيل دخول الموظفين، وخصوصية استجابات الشبكة والمرفقات، وتعارضات المزامنة، لم تُختبر على خدمة مركزية لأنها لم تُربط بعد. المتطلبات المتبقية موثقة في [نطاق 0.3](UPGRADE_0.3.md) و[المواصفات المعتمدة](APPROVED_SCOPE.md).
